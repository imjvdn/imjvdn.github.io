Engineering and evaluating a complete solution

The software-design enhancement separates the dashboard's interface, service logic, domain rules, configuration, and repository. Injecting a repository lets tests supply controlled records or failures without requiring a live database. It also gives a future maintainer a smaller area to change. The original software-design version has a 58-test baseline, including live database checks. I learned that clear boundaries help most when they make a specific behavior easier to test or explain.

The algorithm enhancement adds a nearest-candidate shortlist using Haversine distance and a bounded heap. I compare it with a full-sort reference and test known distances, tied distances, invalid locations, and the requested shortlist limit. In the recorded ranking-only benchmark, 100,000 records with a shortlist of 10 took 273.618 ms for the heap and 345.706 ms for the full sort. Traced temporary allocation was about 3.65 KiB versus 17,970.02 KiB. Those measurements exclude database reads and the prebuilt input records. The full sort was faster for the smallest dataset with the larger shortlist, so the evidence supports a trade-off rather than a universal speed claim.

The database enhancement changes how records reach the application. Keyset pages limit the displayed rows, the breed summary covers the full selected category, and a projected cursor supplies records to the ranking algorithm. In the recorded 10,000-record benchmark, streaming reduced peak traced Python allocation from about 13.19 MB to 0.16 MB but took longer. I also added import preview, collection validation, and permission checks. The configured suite passed all 160 tests, including 27 live MongoDB cases. These results use fictional data on a local test system; they do not establish production performance or suitability for a real rescue organization.

Changes and design decisions

The original dashboard callback built rescue queries, requested data, and prepared table rows in one function. The enhanced app.py handles presentation and callbacks, domain.py defines typed animal records and rescue rules, service.py handles searches and result states, and repository.py provides interchangeable data adapters. The Settings class in config.py supplies runtime configuration. The application factory accepts a repository as an argument, which is dependency injection: tests can supply controlled records or failures instead of a live database. This makes it possible to check behavior without starting MongoDB or changing production data.

I preserved the original rescue eligibility conditions, including the inclusive age boundaries, and kept the table, chart, column highlighting, and map. Unsupported rescue choices now produce a validation message instead of silently requesting all records. The table uses a permanent ID for each record, following Dash's support for row identities (Plotly, n.d.). Sorting therefore does not change the selected animal. Changing a rescue category or refreshing clears the selection and returns to page one. If a table filter excludes the selected animal, the map asks for a current selection. This explicit behavior replaces the original use of unchecked row positions.

Location validation accepts finite numeric coordinates only within the permitted latitude and longitude ranges. Missing values stay missing, and valid zero coordinates remain usable. When an animal has invalid coordinates, its record remains visible while the map explains why a location is unavailable. Empty results clear the chart and map. Database errors become a safe message with a retry option. Application logs record the failed operation without raw driver messages, and credentials are read from the environment rather than stored in the source. Debug mode defaults to off, and the server binds to the local computer. The repository exposes only reads. A live local test also confirms that the dashboard account cannot write to the test database.

Verification and limits

The automated suite passes 58 tests in Python 3.12. Tests cover rescue eligibility boundaries, invalid coordinates, empty results, stable record IDs, configuration, and failure recovery. HTTP tests exercise Dash callbacks. Unit tests check MongoDB query construction and simulated errors; the live tests below check the real database. These results verify behavior, not performance.

Browser checks also confirmed that Water Rescue returns three fictional animals, selecting River displays a marker, selecting Bay displays a missing-location message, and a table filter with no matches clears both views. The README explains installation, sample mode, Mongo settings, selection rules, and verification. Seven live integration tests passed against MongoDB 8.0.28 with 14 fictional records. All four category totals matched expectations; unauthenticated reads and dashboard-account writes were rejected. Browser checks confirmed a safe error during a real database outage and recovery after restart. The original shelter dataset was not tested. The table still loads every matching record and pages in the browser. I make no claim of lower memory use or faster queries at this stage. Dash warns that DataTable will be removed in a future major release, so the tested version is pinned and that maintenance limit is documented.

Reflection on the enhancement

This enhancement makes the difference between a working screen and a testable design concrete. The original notebook could display results, but reproducing an empty result or database failure required the surrounding environment. An injected repository makes those cases predictable. A second lesson is that identity and position serve different purposes: a row number is useful for display, but it should not decide which animal a map represents after sorting or filtering. Writing that rule explicitly also made the error states easier to explain.

The main challenge was preserving the original rescue workflow while changing its internal structure. I kept the existing framework and query conditions, then added tests around the boundaries most likely to break. The missing original dataset was another limitation. Clearly labeled fictional records supported both sample-mode checks and live local MongoDB tests without claiming verification of the original shelter dataset. The extra modules add some overhead to a small project, but the separation gives the later algorithm and database enhancements clear places to fit.

from pymongo import MongoClient

from urllib.parse import quote_plus

from bson.objectid import ObjectId





class AnimalShelter(object):

    """CRUD operations for Animal collection in MongoDB"""



    def __init__(self):

        USER = 'REDACTED_FOR_SUBMISSION'

        PASS = quote_plus('REDACTED_FOR_SUBMISSION')

        HOST = 'localhost'

        PORT = 27017

        DB = 'aac'

        COL = 'animals'



        self.client = MongoClient('mongodb://%s:%s@%s:%d' % (USER, PASS, HOST, PORT))

        self.database = self.client['%s' % DB]

        self.collection = self.database['%s' % COL]



    def create(self, data):

        if data is not None:

            result = self.collection.insert_one(data)

            return result.acknowledged

        else:

            raise Exception("Nothing to save, because data parameter is empty")



    def read(self, query):

        if query is not None:

            data = self.collection.find(query, {"_id": False})

            return list(data)

        else:

            raise Exception("Nothing to read, because query parameter is empty")



    def update(self, query, new_values):

        if query is not None and new_values is not None:

            result = self.collection.update_many(query, new_values)

            return result.modified_count

        else:

            raise Exception("Nothing to update, because query or new_values parameter is empty")



    def delete(self, query):

        if query is not None:

            result = self.collection.delete_many(query)

            return result.deleted_count

        else:

            raise Exception("Nothing to delete, because query parameter is empty")

## Tradeoffs



Keeping Dash and its table avoids changing both the framework and architecture at once. The dependency is pinned because DataTable is deprecated for a future major Dash release. A read-only repository interface narrows application behavior but does not prove the database account lacks write permissions. The local fixture database now rejects a no-match write from the dashboard account. Broader production permission tests remain later work.



Selection is cleared after rescue-category changes and refreshes. Table sorting uses stable IDs. Table filtering suppresses the map if the selected ID is no longer visible. These explicit rules replace the original fallback to a positional first row. Code remains independently testable, though additional files and model conversions add maintenance overhead compared with a single notebook.

## Design and behavior



```text

Browser controls

    -> app.py callbacks (presentation)

    -> RescueService (validation, result and error states)

    -> AnimalRepository protocol

        -> InMemoryRepository (fictional records)

        -> MongoRepository (fixed read queries)



domain.py: typed Animal records, rescue rules, coordinates, and identity

config.py: environment settings and safe defaults

```



The factory accepts an injected repository, so tests can simulate results and failures without a live database. The enhanced application exposes no update or delete methods. Mongo connection details are excluded from configuration representations, UI error messages, and application error logs. It does not log raw driver exceptions.



Each row has a permanent `id` derived from Mongo `_id` or the sample `_id`. Selection uses that identity, not a row offset. Sorting does not change which animal is selected. Changing category or refreshing clears selection and returns to page one. A selected animal excluded by a table filter produces a selection prompt instead of showing another animal; restoring the filter may restore that ID's selection. Empty results clear both chart and map. Invalid locations retain the row but replace the map with an explanation. Coordinates (0, 0) are valid and are not treated as missing.



The chart represents all rows remaining after the browser's table filters, across pages. Breeds under 2% are grouped as Other. Table paging remains client-side, with 10 rows displayed per page; all matching results are still loaded. No performance gain is claimed. Haversine ranking, bounded heaps, server-side pagination, database schema rules, permission verification, and measured index selection are reserved for later enhancements.

def finite_number(value):
    # Do not turn missing values or booleans into a legitimate zero coordinate.
    if isinstance(value, bool) or value is None:
        return None
    try:
        number = float(value)
    except (ValueError, TypeError, OverflowError):
        return None
    return number if isfinite(number) else None


def text(value, default='Unknown'):
    return str(value).strip()[:200] if value is not None and str(value).strip() else default

class Animal:
    record_id: str
    animal_id: str
    name: str
    animal_type: str
    breed: str
    sex: str
    age_weeks: float | None
    latitude: float | None
    longitude: float | None

    @classmethod
    def from_document(cls, data: Mapping):
        raw_id = data.get('_id')
        if raw_id is None:
            raw_id = data.get('id')
        if raw_id is None or not str(raw_id).strip():
            raise ValidationError('A record is missing its permanent record ID.')
        return cls(str(raw_id), text(data.get('animal_id')), text(data.get('name'), 'Unnamed'),
                   text(data.get('animal_type')), text(data.get('breed')),
                   text(data.get('sex_upon_outcome')),
                   finite_number(data.get('age_upon_outcome_in_weeks')),
                   finite_number(data.get('location_lat')), finite_number(data.get('location_long')))

    @property
    def coordinates(self):
        if self.latitude is None or self.longitude is None:
            return None
        if not (-90 <= self.latitude <= 90 and -180 <= self.longitude <= 180):
            return None
        return (self.latitude, self.longitude)

    def to_row(self):
        return {'id': self.record_id, 'animal_id': self.animal_id, 'name': self.name,
                'animal_type': self.animal_type, 'breed': self.breed,
                'sex_upon_outcome': self.sex, 'age_upon_outcome_in_weeks': self.age_weeks,
                'location_lat': self.latitude, 'location_long': self.longitude}


def eligible(animal: Animal, category: Category):
    if category == Category.RESET:
        return True
    rule = RULES[category]
    return (animal.animal_type == 'Dog' and animal.breed in rule.breeds
            and animal.sex == rule.sex and animal.age_weeks is not None
            and rule.minimum_age <= animal.age_weeks <= rule.maximum_age)


def rescue_query(category: Category):
    """Construct queries from an enum, never from a user-supplied dictionary."""
    if category == Category.RESET:
        return {}
    rule = RULES[category]
    return {'animal_type': 'Dog', 'breed': {'$in': list(rule.breeds)},
            'sex_upon_outcome': rule.sex,
            'age_upon_outcome_in_weeks': {'$gte': rule.minimum_age, '$lte': rule.maximum_age}}

def normalize(documents):
    animals = [Animal.from_document(doc) for doc in documents]
    ids = [animal.record_id for animal in animals]
    if len(set(ids)) != len(ids):
        raise ValidationError('Record IDs must be unique.')
    return animals

        self._animals = tuple(animals)

    def from_file(cls, path):

        except (OSError, ValueError, TypeError, AttributeError):

class MongoRepository:
    def __init__(self, collection, client=None):
        self._collection = collection
        self._client = client

    @classmethod
    def connect(cls, settings):
        try:
            client = MongoClient(settings.mongo_uri, serverSelectionTimeoutMS=2000,
                                 connectTimeoutMS=2000, socketTimeoutMS=2000)
            return cls(client[settings.database][settings.collection], client)
        except (PyMongoError, ValueError, TypeError):
            raise RepositoryError('Database configuration could not be used.') from None

        # Milestone Two preserves full result loading. Server-side paging is future work.
        projection = {key: 1 for key in ('_id', 'animal_id', 'name', 'animal_type', 'breed',
                      'sex_upon_outcome', 'age_upon_outcome_in_weeks', 'location_lat', 'location_long')}

def breed_counts(animals):
    counts = Counter(a.breed for a in animals)
    total = sum(counts.values())

With the new feature, a user enters a center location and chooses how many results to return. The ranking is based only on distance; it does not judge training suitability or calculate driving routes.

Implementation and reasoning

I used the Haversine formula to estimate the distance between two locations in kilometers, treating Earth as a sphere. The calculation keeps one intermediate value between zero and one so floating-point rounding does not cause errors near opposite points on the globe (Veness, n.d.). The input checks require finite coordinates within valid latitude and longitude ranges, plus a whole-number shortlist size from 1 to 100. Records with missing or invalid locations are left out, and the application tells the user how many were excluded. It rounds distances only when displaying them.

The algorithm reads the records one at a time and keeps up to k candidates in a bounded max-heap. Here, k is the requested shortlist size. It compares each candidate using the full pair of unrounded distance and permanent record ID. Reversing that comparison puts the worst retained candidate at the root, even when distances tie. Once the heap is full, a better candidate replaces the root. Otherwise, the heap stays as it is. This means it always holds the best candidates seen so far. At the end, I sort the retained candidates from best to worst. Python's heap tools support this approach, but getting the comparison order right is essential (Python Software Foundation, n.d.).

For k greater than one, selecting candidates takes O(n log k) time, followed by O(k log k) to sort the shortlist, with O(k) additional storage. When k is one, the scan takes O(n) time. To check the results, I also added a full-sort reference that calculates the same distances, sorts all valid candidates, and returns the first k. That version takes O(n log n) time and O(n) candidate storage. The repository still loads all matching records into memory before ranking begins, so the dashboard's total input storage remains O(n). The O(k) storage benefit applies to the ranking step.

"""Deterministic ranking-only comparison; excludes DB/network/input storage.

One warm-up; five timed runs without tracing, plus five separate traced runs.
Outputs raw samples, medians, Python/platform details, and exact correctness checks.
"""
from pathlib import Path
from time import perf_counter
from statistics import median
import gc, json, platform, random, tracemalloc
from rescue_dashboard.domain import Animal
from rescue_dashboard.ranking import nearest_heap, nearest_full_sort

def dataset(n):
    rng=random.Random(499)
    return [Animal(f'{i:09}','DEMO','Synthetic','Dog','Labrador Retriever Mix','Intact Female',30,
                   rng.uniform(-90,90),rng.uniform(-180,180)) for i in range(n)]

def run():
    report={'seed':499,'repetitions':5,'warmups':1,'python':platform.python_version(),
            'platform':platform.platform(),'scope':'Ranking only; prebuilt input excluded; timing and memory measured separately.', 'results':[]}
    for n in [1000,10000,100000]:
        records=dataset(n)
        for k in [10,100]:
            expected=nearest_full_sort(iter(records),30.2672,-97.7431,k)
            assert nearest_heap(iter(records),30.2672,-97.7431,k).candidates==expected.candidates
            for name,fn in [('heap',nearest_heap),('full_sort',nearest_full_sort)]:
                fn(iter(records),30.2672,-97.7431,k)
                durations=[]; peaks=[]
                for _ in range(5):
                    gc.collect(); start=perf_counter()
                    result=fn(iter(records),30.2672,-97.7431,k)
                    durations.append((perf_counter()-start)*1000)
                    assert result.candidates==expected.candidates
                for _ in range(5):
                    gc.collect(); tracemalloc.start()
                    result=fn(iter(records),30.2672,-97.7431,k)
                    peaks.append(tracemalloc.get_traced_memory()[1]); tracemalloc.stop()
                    assert result.candidates==expected.candidates
                row={'n':n,'k':k,'algorithm':name,'median_ms':round(median(durations),3),
                     'median_peak_bytes':int(median(peaks)),'raw_ms':durations,'raw_peak_bytes':peaks,
                     'peak_retained':result.peak_retained,'ordered_results_match':True}
                report['results'].append(row)
                print(n,k,name,row['median_ms'],row['median_peak_bytes'],flush=True)
    Path('docs/benchmark_results.json').write_text(json.dumps(report,indent=2),encoding='utf-8')

if __name__=='__main__': run()

Validate finite center coordinates and integer k in [1,100] before querying. Apply the existing rescue eligibility filter. Exclude invalid record locations and count them. ## Design and behavior



```text

Browser controls

    -> app.py callbacks (presentation)

    -> RescueService (validation, result and error states)

    -> AnimalRepository protocol

        -> InMemoryRepository (fictional records)

        -> MongoRepository (fixed read queries)



domain.py: typed Animal records, rescue rules, coordinates, and identity

config.py: environment settings and safe defaults

```



The factory accepts an injected repository, so tests can simulate results and failures without a live database. The enhanced application exposes no update or delete methods. Mongo connection details are excluded from configuration representations, UI error messages, and application error logs. It does not log raw driver exceptions.



Each row has a permanent `id` derived from Mongo `_id` or the sample `_id`. Selection uses that identity, not a row offset. Sorting does not change which animal is selected. Empty results clear both chart and map. Invalid locations retain the row but replace the map with an explanation. Coordinates (0, 0) are valid and are not treated as missing.



The chart represents all rows remaining after the browser's table filters, across pages. Breeds under 2% are grouped as Other.             return [], result.message

        app.run(host=settings.host, port=settings.port, debug=settings.debug)

    main()

def finite_number(value):
    # Do not turn missing values or booleans into a legitimate zero coordinate.
    if isinstance(value, bool) or value is None:
        return None
    try:
        number = float(value)
    except (ValueError, TypeError, OverflowError):
        return None
    return number if isfinite(number) else None


def text(value, default='Unknown'):
    return str(value).strip()[:200] if value is not None and str(value).strip() else default


@dataclass(frozen=True)
class Animal:
    record_id: str
    animal_id: str
    name: str
    animal_type: str
    breed: str
    sex: str
    age_weeks: float | None
    latitude: float | None
    longitude: float | None

    @classmethod
    def from_document(cls, data: Mapping):
        raw_id = data.get('_id')
        if raw_id is None:
            raw_id = data.get('id')
        if raw_id is None or not str(raw_id).strip():
            raise ValidationError('A record is missing its permanent record ID.')
        return cls(str(raw_id), text(data.get('animal_id')), text(data.get('name'), 'Unnamed'),
                   text(data.get('animal_type')), text(data.get('breed')),
                   text(data.get('sex_upon_outcome')),
                   finite_number(data.get('age_upon_outcome_in_weeks')),
                   finite_number(data.get('location_lat')), finite_number(data.get('location_long')))

    @property
    def coordinates(self):
        if self.latitude is None or self.longitude is None:
            return None
        if not (-90 <= self.latitude <= 90 and -180 <= self.longitude <= 180):
            return None
        return (self.latitude, self.longitude)

    def to_row(self):
        return {'id': self.record_id, 'animal_id': self.animal_id, 'name': self.name,
                'animal_type': self.animal_type, 'breed': self.breed,
                'sex_upon_outcome': self.sex, 'age_upon_outcome_in_weeks': self.age_weeks,
                'location_lat': self.latitude, 'location_long': self.longitude}


def eligible(animal: Animal, category: Category):
    if category == Category.RESET:
        return True
    rule = RULES[category]
    return (animal.animal_type == 'Dog' and animal.breed in rule.breeds
            and animal.sex == rule.sex and animal.age_weeks is not None
            and rule.minimum_age <= animal.age_weeks <= rule.maximum_age)


def rescue_query(category: Category):
    """Construct queries from an enum, never from a user-supplied dictionary."""
    if category == Category.RESET:
        return {}
    rule = RULES[category]
    return {'animal_type': 'Dog', 'breed': {'$in': list(rule.breeds)},
            'sex_upon_outcome': rule.sex,
            'age_upon_outcome_in_weeks': {'$gte': rule.minimum_age, '$lte': rule.maximum_age}}

"""Nearest eligible records, with a bounded max-heap and full-sort reference.

Keys are (unrounded great-circle distance in km, permanent record ID).
Input records must have unique IDs, as enforced by the repository boundary.
"""
from dataclasses import dataclass
from math import radians, sin, cos, atan2, sqrt
import heapq
from .domain import Animal, ValidationError, finite_number

EARTH_RADIUS_KM = 6371.0088

def validate_request(latitude, longitude, k):
    lat, lon, count = map(finite_number, (latitude, longitude, k))
    if lat is None or lon is None or not (-90 <= lat <= 90 and -180 <= lon <= 180):
        raise ValidationError('Enter a finite latitude from -90 to 90 and longitude from -180 to 180.')
    if count is None or not count.is_integer() or not 1 <= count <= 100:
        raise ValidationError('Enter a whole-number shortlist size from 1 to 100.')
    return (lat, lon), int(count)

def haversine_km(first, second):
    """Great-circle distance on a sphere; callers supply valid coordinates."""
    lat1, lon1 = map(radians, first)
    lat2, lon2 = map(radians, second)
    value = sin((lat2-lat1)/2)**2 + cos(lat1)*cos(lat2)*sin((lon2-lon1)/2)**2
    value = min(1.0, max(0.0, value))
    return 2 * EARTH_RADIUS_KM * atan2(sqrt(value), sqrt(1-value))

@dataclass(frozen=True)
class Candidate:
    animal: Animal
    distance_km: float

    @property
    def key(self):
        return self.distance_km, self.animal.record_id

    def to_row(self):
        return {**self.animal.to_row(), 'distance_km': round(self.distance_km, 3)}

@dataclass(frozen=True)
class RankingResult:
    candidates: tuple[Candidate, ...]
    examined: int
    excluded: int
    peak_retained: int

@dataclass
class _WorstFirst:
    candidate: Candidate

    def __lt__(self, other):
        # Reverse the COMPLETE key so even a distance tie has the worst ID at root.
        return self.candidate.key > other.candidate.key

def nearest_heap(animals, latitude, longitude, k):
    center, count = validate_request(latitude, longitude, k)
    heap = []
    examined = excluded = peak = 0
    for animal in animals:
        examined += 1
        location = animal.coordinates
        if location is None:
            excluded += 1
            continue
        candidate = Candidate(animal, haversine_km(center, location))
        if len(heap) < count:
            heapq.heappush(heap, _WorstFirst(candidate))
            peak = max(peak, len(heap))
        elif candidate.key < heap[0].candidate.key:
            heapq.heapreplace(heap, _WorstFirst(candidate))
    return RankingResult(tuple(sorted((entry.candidate for entry in heap), key=lambda c:c.key)),
                         examined, excluded, peak)

def nearest_full_sort(animals, latitude, longitude, k):
    """New correctness/reference baseline, not functionality in the original app."""
    center, count = validate_request(latitude, longitude, k)
    candidates = []
    examined = excluded = 0
    for animal in animals:
        examined += 1
        location = animal.coordinates
        if location is None:
            excluded += 1
        else:
            candidates.append(Candidate(animal, haversine_km(center, location)))
    candidates.sort(key=lambda c:c.key)
    return RankingResult(tuple(candidates[:count]), examined, excluded, len(candidates))

class RepositoryError(RuntimeError):
    pass


class AnimalRepository(Protocol):
    def find(self, category: Category) -> list[Animal]: ...
    def close(self) -> None: ...


def normalize(documents):
    animals = [Animal.from_document(doc) for doc in documents]
    ids = [animal.record_id for animal in animals]
    if len(set(ids)) != len(ids):
        raise ValidationError('Record IDs must be unique.')
    return animals


class InMemoryRepository:
    def __init__(self, animals):
        self._animals = tuple(animals)

    @classmethod
    def from_file(cls, path):
        try:
            return cls(normalize(json.loads(path.read_text(encoding='utf-8'))))
        except (OSError, ValueError, TypeError, AttributeError):
            raise RepositoryError('Sample records could not be loaded.') from None

    def find(self, category):
        return [a for a in self._animals if eligible(a, category)]

    def close(self):
        pass


class MongoRepository:
    def __init__(self, collection, client=None):
        self._collection = collection
        self._client = client

    @classmethod
    def connect(cls, settings):
        try:
            client = MongoClient(settings.mongo_uri, serverSelectionTimeoutMS=2000,
                                 connectTimeoutMS=2000, socketTimeoutMS=2000)
            return cls(client[settings.database][settings.collection], client)
        except (PyMongoError, ValueError, TypeError):
            raise RepositoryError('Database configuration could not be used.') from None

    def find(self, category):
        # Milestone Two preserves full result loading. Server-side paging is future work.
        projection = {key: 1 for key in ('_id', 'animal_id', 'name', 'animal_type', 'breed',
                      'sex_upon_outcome', 'age_upon_outcome_in_weeks', 'location_lat', 'location_long')}
        try:
            with self._collection.find(rescue_query(category), projection) as cursor:
                return normalize(cursor)
        except (PyMongoError, ValidationError, TypeError, AttributeError):
            raise RepositoryError('Database records could not be loaded.') from None

    def close(self):
        if self._client is not None:
            self._client.close()


class UnavailableRepository:
    """Keeps the interface available when local sample configuration is invalid."""
    def find(self, category):
        raise RepositoryError('Data source unavailable.')

    def close(self):
        pass

from collections import Counter
from dataclasses import dataclass
import logging
from .domain import Animal, Category, ValidationError
from .repository import AnimalRepository, RepositoryError

logger = logging.getLogger(__name__)


@dataclass(frozen=True)
class SearchResult:
    animals: tuple[Animal, ...]
    message: str
    failed: bool = False


class RescueService:
    def __init__(self, repository: AnimalRepository):
        self.repository = repository

    def search(self, choice):
        try:
            category = Category.parse(choice)
        except ValidationError as error:
            return SearchResult((), str(error), True)
        try:
            animals = tuple(self.repository.find(category))
        except RepositoryError:
            # Never log exception text: driver errors can contain hosts or credentials.
            logger.warning('animal_search_failed category=%s', category.name)
            return SearchResult((), 'Unable to load animals. Check the data source and select Retry.', True)
        if not animals:
            return SearchResult((), 'No animals match this rescue category.')
        return SearchResult(animals, f'{len(animals)} animals loaded. Select a row to show its location.')


def selected_animal(animals, selected_ids):
    if not isinstance(selected_ids, list) or len(selected_ids) != 1:
        return None
    selected_id = selected_ids[0]
    return next((a for a in animals if a.record_id == selected_id), None)


def breed_counts(animals):
    counts = Counter(a.breed for a in animals)
    total = sum(counts.values())
    grouped = Counter()
    for breed, count in counts.items():
        grouped['Other' if count < total * .02 else breed] += count
    return dict(sorted(grouped.items()))

What changed and why

The table now requests a page from MongoDB instead of loading the full category into the browser. It displays 10, 25, or 50 rows and uses the first or last permanent record ID to move backward or forward. The query asks for only the fields the dashboard uses and fetches one extra row to check whether another page exists. I validate page sizes and typed cursor values before accessing the database. The fixed record-ID order makes navigation predictable. MongoDB explains that range queries can avoid the growing scan needed by large skip offsets (MongoDB, n.d.-a).

I removed arbitrary browser sorting and text filtering as a deliberate trade-off. With only one page loaded, those controls could make a partial result look complete. The rescue category controls remain. Changing category, page size, or refreshing returns to the first page and clears the selection. Paging is not a snapshot: records edited between requests can change later pages, so refresh restarts the view.

The breed chart uses a separate match-and-group aggregation for the full category. It does not summarize just the visible page. The map still uses the selected row on that page. The shortlist also considers the entire category, but now reads projected records through a cursor in batches of 100. The existing heap keeps only the best requested candidates. If reading the cursor fails, the app clears the ranking rather than showing an incomplete answer. Streaming limits input buffering; it does not avoid scanning all eligible records.

I added an import preview that reports malformed or duplicate rows before writing anything. Apply refuses an existing collection and refuses a batch with rejected rows. A strict MongoDB validator checks IDs, required text, ages, and coordinate ranges. Missing locations stay missing instead of becoming zero. A separate reader account runs the dashboard, while a maintenance account handles setup and indexes. """Nearest eligible records, with a bounded max-heap and full-sort reference.

Keys are (unrounded great-circle distance in km, permanent record ID).
Input records must have unique IDs, as enforced by the repository boundary.

from dataclasses import dataclass
from math import radians, sin, cos, atan2, sqrt
import heapq
from .domain import Animal, ValidationError, finite_number

EARTH_RADIUS_KM = 6371.0088

def validate_request(latitude, longitude, k):
    lat, lon, count = map(finite_number, (latitude, longitude, k))
    if lat is None or lon is None or not (-90 <= lat <= 90 and -180 <= lon <= 180):
        raise ValidationError('Enter a finite latitude from -90 to 90 and longitude from -180 to 180.')
    if count is None or not count.is_integer() or not 1 <= count <= 100:
        raise ValidationError('Enter a whole-number shortlist size from 1 to 100.')
    return (lat, lon), int(count)

def haversine_km(first, second):
    """Great-circle distance on a sphere; callers supply valid coordinates."""
    lat1, lon1 = map(radians, first)
    lat2, lon2 = map(radians, second)
    value = sin((lat2-lat1)/2)**2 + cos(lat1)*cos(lat2)*sin((lon2-lon1)/2)**2
    value = min(1.0, max(0.0, value))
    return 2 * EARTH_RADIUS_KM * atan2(sqrt(value), sqrt(1-value))

@dataclass(frozen=True)
class Candidate:
    animal: Animal
    distance_km: float

    @property
    def key(self):
        return self.distance_km, self.animal.record_id

    def to_row(self):
        return {**self.animal.to_row(), 'distance_km': round(self.distance_km, 3)}

@dataclass(frozen=True)
class RankingResult:
    candidates: tuple[Candidate, ...]
    examined: int
    excluded: int
    peak_retained: int

@dataclass
class _WorstFirst:
    candidate: Candidate

    def __lt__(self, other):
        # Reverse the COMPLETE key so even a distance tie has the worst ID at root.
        return self.candidate.key > other.candidate.key

def nearest_heap(animals, latitude, longitude, k):
    center, count = validate_request(latitude, longitude, k)
    heap = []
    examined = excluded = peak = 0
    for animal in animals:
        examined += 1
        location = animal.coordinates
        if location is None:
            excluded += 1
            continue
        candidate = Candidate(animal, haversine_km(center, location))
        if len(heap) < count:
            heapq.heappush(heap, _WorstFirst(candidate))
            peak = max(peak, len(heap))
        elif candidate.key < heap[0].candidate.key:
            heapq.heapreplace(heap, _WorstFirst(candidate))
    return RankingResult(tuple(sorted((entry.candidate for entry in heap), key=lambda c:c.key)),
                         examined, excluded, peak)

def nearest_full_sort(animals, latitude, longitude, k):
    """New correctness/reference baseline, not functionality in the original app."""
    center, count = validate_request(latitude, longitude, k)
    candidates = []
    examined = excluded = 0
    for animal in animals:
        examined += 1
        location = animal.coordinates
        if location is None:
            excluded += 1
        else:
            candidates.append(Candidate(animal, haversine_km(center, location)))
    candidates.sort(key=lambda c:c.key)
    return RankingResult(tuple(candidates[:count]), examined, excluded, len(candidates))

    animals = [Animal.from_document(doc) for doc in documents]

    ids = [animal.record_id for animal in animals]

    if len(set(ids)) != len(ids):

        raise ValidationError('Record IDs must be unique.')

    return animals

        except (OSError, ValueError, TypeError, AttributeError):

class _MongoReference:

    def __init__(self, collection, client=None):

        self._collection = collection

        self._client = client



    @classmethod

    def connect(cls, settings):

        try:

            client = MongoClient(settings.mongo_uri, serverSelectionTimeoutMS=2000,

                                 connectTimeoutMS=2000, socketTimeoutMS=2000)

            return cls(client[settings.database][settings.collection], client)

        except (PyMongoError, ValueError, TypeError):

            raise RepositoryError('Database configuration could not be used.') from None



    def find(self, category):

        # Milestone Two preserves full result loading. Server-side paging is future work.

        projection = {key: 1 for key in ('_id', 'animal_id', 'name', 'animal_type', 'breed',

                      'sex_upon_outcome', 'age_upon_outcome_in_weeks', 'location_lat', 'location_long')}

        try:

            with self._collection.find(rescue_query(category), projection) as cursor:

                return normalize(cursor)

        except (PyMongoError, ValidationError, TypeError, AttributeError):

            raise RepositoryError('Database records could not be loaded.') from None



    def close(self):

        if self._client is not None:

            self._client.close()

class InMemoryRepository(_MemoryReference):

    def page(self, category, size=10, cursor=None, direction='next'):

        category, boundary = request(category, size, cursor, direction)

        records = sorted(self.find(category), key=lambda a:a.record_id)

        candidates = [a for a in records if boundary is None or

                      (a.record_id > boundary if direction == 'next' else a.record_id < boundary)]

        rows = candidates[:size] if direction == 'next' else candidates[-size:]

        return Page(tuple(rows), encode_id(rows[0].record_id) if rows else None,

                    encode_id(rows[-1].record_id) if rows else None,

                    bool(rows and any(a.record_id < rows[0].record_id for a in records)),

                    bool(rows and any(a.record_id > rows[-1].record_id for a in records)))



    def summary(self, category):

        return dict(sorted(Counter(a.breed for a in self.find(Category.parse(category))).items()))



    def iter_find(self, category):

        category = Category.parse(category)

        return (a for a in self._animals if eligible(a, category))



class MongoRepository(_MongoReference):

    def page(self, category, size=10, cursor=None, direction='next'):

        category, boundary = request(category, size, cursor, direction)

        query = rescue_query(category)

        if boundary is not None:

            query['_id'] = {'$gt' if direction == 'next' else '$lt': boundary}

        order = 1 if direction == 'next' else -1

        try:

            with self._collection.find(query, PROJECTION).sort('_id',order).limit(size+1).max_time_ms(5000) as cur:

                docs = list(cur)

            extra = len(docs) > size

            docs = docs[:size]

            if direction == 'previous': docs.reverse()

            rows = tuple(normalize(docs))

            return Page(rows, encode_id(docs[0]['_id']) if docs else None,

                        encode_id(docs[-1]['_id']) if docs else None,

                        (boundary is not None if direction == 'next' else extra),

                        (extra if direction == 'next' else boundary is not None))

        except (PyMongoError, ValidationError, TypeError, AttributeError):

            raise RepositoryError('Database page could not be loaded.') from None



    def summary(self, category):

        category = Category.parse(category)

        pipeline = [{'$match':rescue_query(category)},

                    {'$group':{'_id':'$breed','count':{'$sum':1}}}, {'$sort':{'_id':1}}]

        try:

            with self._collection.aggregate(pipeline, maxTimeMS=5000) as cur:

                return {str(row['_id']):row['count'] for row in cur}

        except (PyMongoError, TypeError, AttributeError):

            raise RepositoryError('Database summary could not be loaded.') from None



    def iter_find(self, category):

        category = Category.parse(category)

        # A single cursor holds at most a driver batch plus the ranking heap.

        # MongoDB enforces unique _id values. Schema setup requires one ID type.

        try:

            with self._collection.find(rescue_query(category), PROJECTION).batch_size(100).max_time_ms(5000) as cur:

                for doc in cur:

                    yield Animal.from_document(doc)

        except (PyMongoError, ValidationError, TypeError, AttributeError):

            raise RepositoryError('Database ranking records could not be loaded.') from None

class SearchResult:
    animals: tuple[Animal, ...]

class RescueService:
    def __init__(self, repository: AnimalRepository):
        self.repository = repository

    def search(self, choice):
        try:
            category = Category.parse(choice)
        except ValidationError as error:
            return SearchResult((), str(error), True)
        try:
            animals = tuple(self.repository.find(category))
        except RepositoryError:
            # Never log exception text: driver errors can contain hosts or credentials.
            logger.warning('animal_search_failed category=%s', category.name)
            return SearchResult((), 'Unable to load animals. Check the data source and select Retry.', True)
        if not animals:
            return SearchResult((), 'No animals match this rescue category.')
        return SearchResult(animals, f'{len(animals)} animals loaded. Select a row to show its location.')


def selected_animal(animals, selected_ids):
    if not isinstance(selected_ids, list) or len(selected_ids) != 1:
        return None
    selected_id = selected_ids[0]
    return next((a for a in animals if a.record_id == selected_id), None)


def breed_counts(animals):
    counts = Counter(a.breed for a in animals)
    total = sum(counts.values())
    grouped = Counter()
    for breed, count in counts.items():
        grouped['Other' if count < total * .02 else breed] += count
    return dict(sorted(grouped.items()))

import argparse, json, os, math

from pathlib import Path

from bson import ObjectId



TEXT_FIELDS = ('animal_id','name','animal_type','breed','sex_upon_outcome')



def schema(id_type='string'):

    if id_type not in ('string','objectId'): raise ValueError('Unsupported ID type.')

    fields = {'_id': {'bsonType':id_type}}

    if id_type == 'string': fields['_id'].update(minLength=1,maxLength=200,pattern=r'^[^\x00]+$')

    fields.update({key:{'bsonType':'string','minLength':1,'maxLength':200} for key in TEXT_FIELDS})

    fields['age_upon_outcome_in_weeks']={'bsonType':['int','long','double','decimal'],'minimum':0,'maximum':10000}

    for key,low,high in [('location_lat',-90,90),('location_long',-180,180)]:

        fields[key]={'bsonType':['int','long','double','decimal','null'],'minimum':low,'maximum':high}

    return {'$jsonSchema':{'bsonType':'object','required':['_id',*TEXT_FIELDS,'age_upon_outcome_in_weeks'],

                          'properties':fields}}



def validator(id_type='string'):

    value=schema(id_type)

    return value



def validate_record(doc, id_type='string'):

    if not isinstance(doc,dict): return 'Record must be an object.'

    key=doc.get('_id')

    if id_type=='string':

        if not isinstance(key,str) or not key.strip() or len(key)>200 or '\x00' in key: return 'Invalid string _id.'

    elif not isinstance(key,ObjectId): return 'ObjectId required.'

    for field in TEXT_FIELDS:

        v=doc.get(field)

        if not isinstance(v,str) or not v.strip() or len(v)>200 or v!=v.strip(): return 'Invalid '+field+'.'

    for field,lo,hi,optional in [('age_upon_outcome_in_weeks',0,10000,False),

                ('location_lat',-90,90,True),('location_long',-180,180,True)]:

        v=doc.get(field)

        if optional and v is None: continue

        if isinstance(v,bool) or not isinstance(v,(int,float)) or not math.isfinite(v) or not lo<=v<=hi:

            return 'Invalid '+field+'.'

    return None



def preview(records):

    accepted=[]; rejected=[]; seen=set()

    for row,doc in enumerate(records,1):

        reason=validate_record(doc)

        if reason is None and doc['_id'] in seen: reason='Duplicate _id in import.'

        if reason: rejected.append({'row':row,'reason':reason})

        else: accepted.append(doc);seen.add(doc['_id'])

    return accepted,rejected



def create_collection(db, name, records, id_type='string'):

    if name in db.list_collection_names(): raise ValueError('Collection already exists; no changes made.')

    if any(validate_record(doc,id_type) for doc in records): raise ValueError('Preview contains malformed records.')

    collection=db.create_collection(name, validator=validator(id_type),validationLevel='strict',validationAction='error')

    if records: collection.insert_many(records)

    return collection



def main():

    parser=argparse.ArgumentParser(description=__doc__)

    parser.add_argument('input',type=Path);parser.add_argument('--database',required=True)

    args=parser.parse_args()

    records=json.loads(args.input.read_text(encoding='utf-8'))

        create_collection(client[args.database],args.collection,accepted)

    print('Validated collection created. No existing collection was replaced.')



if __name__=='__main__': main()

# ----- Pie chart: breed distribution of currently visible data -----
@app.callback(
    Output('graph-id', 'children'),
    [Input('datatable-id', 'derived_virtual_data')]
)
def update_graphs(view_data):
    if not view_data:
        return []

    dff = pd.DataFrame.from_dict(view_data)

    breed_counts = dff['breed'].value_counts().reset_index()
    breed_counts.columns = ['breed', 'count']
    threshold = breed_counts['count'].sum() * 0.02
    breed_counts.loc[breed_counts['count'] < threshold, 'breed'] = 'Other'
    breed_counts = breed_counts.groupby('breed', as_index=False).sum()

    fig = px.pie(
        breed_counts,
        names='breed',
        values='count',
        title='Breed Distribution of Filtered Animals',
        hole=0.3
    )
    fig.update_traces(textposition='inside', textinfo='percent+label')
    fig.update_layout(margin={'t': 50, 'b': 10, 'l': 10, 'r': 10})

    return [dcc.Graph(figure=fig)]

    if 'location_lat' not in dff.columns or 'location_long' not in dff.columns:

    lat   = dff.iloc[row]['location_lat']
    lon   = dff.iloc[row]['location_long']
    breed = dff.iloc[row].get('breed', 'Unknown breed')
    name  = dff.iloc[row].get('name', 'Unnamed')

    return [
        dl.Map(
            style={'width': '100%', 'height': '500px'},
            center=[lat, lon],
            zoom=10,
            children=[
                dl.TileLayer(id='base-layer-id'),
                dl.Marker(
                    position=[lat, lon],
                    children=[
                        dl.Tooltip(breed),
                        dl.Popup([
                            html.H4('Animal Name'),
                            html.P(name)
                        ])
                    ]
                )
            ]
        )
